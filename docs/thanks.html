Your receipt is on its way from Polar. Here is what happens next.

1. Connect GitHub to get repository access

Access to the private house-of-arqam/paidextension repository is granted to the GitHub account you connect in your Polar purchase page — nothing is sent until you do.

Open your purchase & connect GitHub

Find the GitHub repository access benefit and click Connect. The invitation arrives at your GitHub email within a minute; accept it and the repo appears under your account. The same page is linked from the Polar receipt email if you need it later.

2. Clone and run the setup

git clone https://github.com/house-of-arqam/paidextension.git my-extension
cd my-extension
git remote rename origin upstream   # keep the kit as `upstream`; push to your own private repo
npm run init          # product name, company, prices, seats, trial length
npm run install:all
npm run check         # lint, types, tests, builds

Then follow docs/setup.md in the repo — or hand the .agents/skills/setup skill to your AI coding agent. The online docs summarize the same path.

3. Updates

Updates land in the same repository as kit-v* tags with a changelog. Pull them with git fetch upstream && git merge upstream/main. Watch the repo on GitHub to get notified.

Help

Questions or problems: open an issue in the repository, or email hello@paidextension.dev. Refunds within 14 days are handled the same way — see the terms.
